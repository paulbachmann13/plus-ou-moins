# Plus ou Moins

Jeu de cartes à jouer entre potes : devine si la prochaine carte sera plus haute, plus basse ou égale.

**Jouer :** https://paulbachmann13.github.io/plus-ou-moins/

Ouvre le lien sur ton téléphone puis « Ajouter à l'écran d'accueil » (Safari : bouton Partager ; Chrome : menu ⋮ → Installer l'application). Le jeu marche ensuite hors connexion.

## Règles

- Le joueur dont c'est le tour devine la carte suivante : ▲ plus, ▼ moins ou = égale.
- Bonne réponse : une carte de plus dans le tas, il continue.
- Raté : il prend autant de pénalités que de cartes dans le tas, le tas repart à 1 et c'est au suivant.
- Après 3 bonnes réponses d'affilée (réglable), il peut passer la main : le tas reste.

Raccourcis : glisser la carte vers le haut ou le bas, ou ↑ ↓ = et Espace au clavier.

Une seule page HTML, sans dépendance. Pour publier une mise à jour, changer `VERSION` dans `sw.js`.
